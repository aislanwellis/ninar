# Ninar

Continhos para dormir, em português do Brasil, para crianças de 0 a 3 anos.

A ficha da criança (nome, menino ou menina, mamãe, papai e irmãozinho) fica salva neste aparelho. Cada história usa esses nomes, dura cerca de 5 a 7 minutos e toca com a voz de uma contadora e um som de fundo do tema.

```bash
npm install
npm run dev
```
